# Bundled Open Fonts

Alis bundles the following open-licensed font families so the shell renders consistently across Linux distributions without requiring AUR `-git` font packages:

| Font Family | Files | License | Upstream |
|---|---|---|---|
| Material Symbols Rounded (Variable) | `MaterialSymbolsRounded.ttf` | Apache-2.0 | Google Fonts (`google/material-design-icons`) |
| Roboto Flex (Variable) | `RobotoFlex-VF.ttf` | SIL Open Font License 1.1 (OFL-1.1) | Google Fonts (`googlefonts/roboto-flex`) |
| Rubik (Variable) | `Rubik-VF.ttf`, `Rubik-Italic-VF.ttf` | SIL Open Font License 1.1 (OFL-1.1) | Google Fonts (`googlefonts/rubik`) |
| Gabarito | `Gabarito/*.ttf` | SIL Open Font License 1.1 (OFL-1.1) | Google Fonts (`naipefoundry/gabarito`) |
| Readex Pro | `ReadexPro/*.ttf` | SIL Open Font License 1.1 (OFL-1.1) | Google Fonts (`ThomasJockin/readexpro`) |
| Oxanium | `Oxanium/*.ttf` | SIL Open Font License 1.1 (OFL-1.1) | Google Fonts (`sevmeyer/oxanium`) |
| Twemoji | `Twemoji.ttf` | MIT (code) / CC-BY-4.0 (graphics) | Twitter / jdecked Twemoji |
