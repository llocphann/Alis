# Alis task tracking — GitHub Issues

**[Open Alis GitHub Issues](https://github.com/llocphann/Alis/issues?q=is%3Aissue+is%3Aopen)** is the **single active backlog** for Alis `dev`, Alis-Companion and Alis-Intergration. Local and Cloud AI use the same Issues and must not write new tasks or status into Markdown.

- **New features:** `[DOMAIN-F##]`
- **Rework/optimization:** `[DOMAIN-R##]`
- **Issues/bugs:** `[DOMAIN-I##]`

Keep stable task codes, search before creating to avoid duplicates, and write concise actionable descriptions. A bot-reported complete task remains an **open Issue** until Owner verified; record technical and owner acceptance separately. Once verified, close as completed. Use [AGENTS.md](../AGENTS.md) for routing, priority and validation.

The previous three Markdown ledgers in `cloud-bot/` are read-only redirects; original snapshots are retained in Git history. Technical research and evidence stay in `docs/` without forming another task board.
